# Claude Code 与 Claude Cowork 正式登陆政府行业

*原文标题：Bringing Claude Code and Claude Cowork to government*

> 原文链接：https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government

[Claude Code](https://claude.com/product/claude-code) 与 [Claude Cowork](https://claude.com/product/cowork) 已在 **Claude for Government Desktop** 中进入公开测试阶段，基于我们商业客户所用的同一款应用，并通过 FedRAMP High 授权环境交付。

借助 Claude Code，公共部门团队可以构建并现代化支撑公共服务的软件系统。Claude Cowork 则直接在桌面文件上工作，让机构员工可以将撰写备忘录、审阅 RFP、处理个案工作以及制作演示文稿等事务委托给 Claude。

升级后的体验同时带来了更丰富的治理能力：管理员可以设置配置默认值，并在各部门之间分配与控制支出；安全团队与授权官员则可获得防篡改的审计日志，以及支持机构 ATO 流程的合规文档。

本次发布让各类机构能够更便捷地采购、授权并部署 AI，以推进各自的使命任务。

## 本次新增内容

**Claude Code 与 Claude Cowork。** 政府机构能以与商业用户相同的节奏获得最新能力。对话历史保存在机构管理的设备本地，推理计算则在 FedRAMP High 授权环境中执行。

**契合财政拨款的计费方式。** 项目办公室既可使用标准席位把 AI 支出与财政拨款挂钩，也可以自行定义席位层级（配置支出与模型限额）。用量按固定增量采购，并设有不可逾越的硬上限。管理员可以在管理控制台按用户、按模型追踪用量；余额告警会在耗尽前自动提醒。

**与部门组织架构相匹配的管理。** 部门级管理员可以向子机构分配席位和预付用量，同时让各子机构独立管理自己的用户。管理员可以使用 SCIM 组映射为特定席位层级设置速率限额、美元上限和允许使用的模型。此外，分层配置可以为子机构设定默认值，包括 Claude 可连接的系统范围、可用的功能集，以及指导 Claude 与用户交互方式的指令。

**设计层面的监管能力。** 每一项管理动作都记录在哈希链审计日志中，组织管理员可直接在产品内审阅。Anthropic 一侧的敏感操作需要双人审批才能执行。用量导出仅包含计量数据，使机构在响应 ATO 与 IG 请求时无需迁移敏感资料。

## 安全与监督

对于评估桌面部署的安全团队，我们正发布《FedRAMP 安全配置指南》作为公开文档，供客户安全地配置其 Claude for Government 产品。

此外，FedRAMP 要求我们提供正式变更通知，其中包含本次变更的详细信息。

最后，新桌面客户端的渗透测试摘要已经就绪，未来还会陆续补充后续的渗透测试报告。变更通知与渗透测试摘要可通过 Anthropic 信任中心在签署 NDA 后获取。该应用通过标准的机构 MDM 平台进行部署。

## 如何开始

Claude for Government 自今日起开放测试。Anthropic 仍是合同与计费主体 —— 政府机构无需另行建立云服务商关系即可上手。

新客户可在 [claude.com/solutions/government](https://claude.com/solutions/government) 申请访问权限。

安全团队可通过 [此链接](https://trust.anthropic.com/resources?s=gutlu13ft6nd7famxolbxg&name=[anthropic]-2025-annual-penetration-testing-reports) 下载渗透测试资料。
