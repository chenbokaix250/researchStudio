# Millennium 与 Anthropic 正在用 Claude 共同打造一位"数字风险分析师"

*原文标题：Millennium and Anthropic are building a digital risk analyst with Claude*

> 原文链接：https://claude.com/blog/millennium-and-anthropic-are-building-a-digital-risk-analyst-with-claude

Anthropic 正与 Millennium —— 全球最大的另类投资管理公司之一 —— 合作，共同开发一位"数字风险分析师"：这位 AI 队友将与该公司风险经理并肩工作、在其监督下运行，负责挖掘新的风险洞察，并就各类资产的风险敞口形成判断。

Claude 和 [Claude Code](https://claude.com/product/claude-code) 目前已在 Millennium 内部得到广泛使用 —— 从交易台、工程团队到核心业务职能部门。Millennium 的"数字风险分析师"扩展了 Claude 的使用方式：让风险经理能够更快、更深入地完成风险头寸分析。

## 用 Claude 评估金融风险

投资行业数十年来一直在借助技术提升风险度量能力，从传统的评估方法走向更复杂的实时情景分析。Millennium 的"数字风险分析师"正是为攻克关键工作流而设计，由 Millennium 自有的专有数据与 Claude 的前沿智能共同驱动。

这位"数字风险分析师"能够跨时间保留并回溯信息，借助新的推理能力解释每日风险变化。这些发现随后由 Millennium 的人工风险经理进行校验与丰富。

> "在 Millennium，我们相信 AI 能为我们员工的成就树立新的标杆，" Millennium 的首席信息官 Vlad Torgovnik 表示。"我们与 Anthropic 的合作就是一个绝佳例证，它展示了 AI 如何在推动核心业务创新的同时，把人的判断置于决策的中心。我们非常期待继续与这位行业领军者合作，共同探索 AI 为业务创造价值的新方式。"

## Millennium 的员工如何使用 Claude

Millennium 是 Claude 和 Claude Code 的早期采用者。员工使用 Claude Code 编写软件、构建产品、改进工作流，覆盖了 Millennium 旗下 340+ 投资团队中的大量团队。

"数字风险分析师" 通过以下方式提供安全、可审计的分析：记录其推理过程、在沙箱环境中测试其动作、并要求人类专家评估与审批其决策。Millennium 的风险专家正与 Anthropic 的研究及应用 AI 团队并肩合作，在 Millennium 的 AI 实验室中共同构建这一系统。

Millennium 正在利用其内部 AI 实验室继续推动前沿探索，针对一系列雄心勃勃的用例对 Anthropic 最新 Claude 模型进行压力测试，并将 Claude 投入到节奏飞快的创新环境中加以使用。

> "金融服务需要的是能在复杂、严苛环境中值得信赖的 AI，" Anthropic 金融服务总经理 Belinda Neal 表示。"Millennium 是 Claude 与 Claude Code 的早期采用者，我们与其风险团队的合作将展示 AI 如何助力 Millennium 风险经理日常所做的分析。"

> "Claude 能够对风险头寸展开推理、解释每日变化，并将其所学带入下一个问题，"Anthropic 资产与财富管理业务负责人 Peter Nolan 说道。"Millennium 的风险经理将借助前沿智能给出自动化建议，以期节省宝贵的时间。"
