正如标题所说，情感博主是会英语的。

首先，我并不是什么英语学霸，之前四级和六级也都是擦边过的，第一次雅思我是6分。

这篇文章，我会把我这两个月如何用 Claude Code、每天只学两个小时完成雅思自学的完整步骤。

不论你现在是什么水平，按照这套方法做，你都可以达到你想要的目标分数。

## 这套计划有四个关键点

1. **不报班，自己学** —— 这样可以省钱。
2. **只学两个月** —— 不需要把战线拖得太长。
3. **每天只学两个小时** —— 不会影响你的日常工作。
4. **必须使用 Claude Code**（用 Codex 也行，逻辑一样）—— 因为我们想不报班、只学两个月、每天还只学两个小时，AI 是必备的。

> 完整视频系列在小红书账号。

## 一、先让 Claude Code 摸底

首先，完整做一套测试（任何模考软件都行）。

- 听力和阅读做完直接看分数。
- 写作留下原文 → 用**雅思写作 Skill** 帮你打分。
- 口语录音/转录交给 Claude Code → 按评分标准反馈。

然后把这次测试的题目、你的答案、写作原文、口语内容，**全部交给 Claude Code**，并告诉它你想考到多少分。

例如：现在 6/6/5/5 平均 5.5，目标 7 分。让 Claude Code 判断每科差多少、时间重点放在哪里。

> **因为每个人的问题不一样。** 有人词汇不够，有人长难句看不懂，有人听不出来，有人写作/口语没人指出错误。所以不能拿着一张通用计划表照学。个性化是在固定计划的内部做的。

作者把自己的学习计划内置在了"雅思 Skill"里，可以直接模仿。

## 二、第一个月：前四周不要练任何题目

> **第一个月，也就是前四周，不要练任何题目。**
>
> 因为单词和句子都看不懂的时候，学再多解题技巧也没用。

前四周所有时间，**全部花在背单词和长难句上**。

### 每日时间分配（第一个月）

| 时段 | 时长 | 内容 |
|------|------|------|
| 第 1 天 | 1h | 单词 + 1h 长难句 |
| 第 2 天起 | 0.5h | 复习昨日单词 + 长难句 |
| 第 2 天起 | 1h | 学今天的单词 |
| 第 2 天起 | 0.5h | 练今天的长难句 |

**每日循环：0.5h 复习 + 1.5h 新学**

一个月后，你会多 **2000-3000 词词汇量**，背过 **100-200 个长难句**。具备这个条件后，第二个月会非常轻松。

## 三、第二个月：开始做真题和输出训练

第二个月开始做真题和输出训练。

作者的安排（仅作参考，应根据自身差距让 Claude Code 调整）：

- **周一、周三、周五**：听力和阅读
- **周二、周四、周六**：口语和写作
- **周日**：完整模考 + 复盘

### 一三五：听力和阅读

听力正式考试 30 分钟 + 阅读 60 分钟 → 一套共 90 分钟。

剩下的 0.5 小时用来**对答案、复盘为什么错**。

> ⚠️ 做的题越多 ≠ 提的分越多。真正应该增加的，是**有效复盘时间**。

### 二四六：口语和写作

- **口语** 0.5h：路上听别人怎么说（每天走路顺便听，不需要专门坐着）。
- **写作** 1.5h：坐下来完成一整套写作训练。

### 周日：完整模考（唯一的例外）

周日单独留出半天做完整模考和复盘。

- 雅思完整考试约 **2 小时 45 分钟**。
- 考完后对答案，记录新的四科成绩。

## 四、为什么每天只学两个小时

> 雅思看的是你的**有效学习时间**，不是你坐在那里一共坐了多久。

很多朋友一天学 4 小时，后面 2 小时脑子已经降速——继续坐着，效率极低，自己也很累。

**每天集中学 2 小时**。如果还有更多时间，分开学。

> 真正的问题不是你一天坐在那里学多久，而是这 2 小时里，你到底有没有**解决自己的问题**。

## 五、让 Claude Code 持续跟踪

> 计划不是第一天做完以后两个月都不变。你需要有一个人**实时看着**你的成绩、错误和进度。

Claude Code（内置模拟考试数据跟踪台）可以做到：

1. **记录**每次模考的四科成绩
2. **分析**这段时间哪些问题解决了、哪些还没解决
3. **调整**下一周的备考计划

## 最后

这就是方法的核心：

- 不报班，自己学
- 只学两个月
- 每天集中学习 2 小时
- 让 Claude Code 负责**摸底 → 制定计划 → 持续跟踪**

具体每科怎么用 AI 快速提分会分几篇写出来。
