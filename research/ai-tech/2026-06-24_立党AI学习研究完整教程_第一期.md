## 关键观点提炼

### 1. 模型选择：普通模型足够用

对于日常agented coding任务，85分和95分的模型**没有显著差异**。好的模型和差的模型差距，普通人是感知不到的。

推荐清单：
- 智谱 Moonshot（月之暗面）
- 阿里通义
- DeepSeek
- MiniMax
- Kimi Code

### 2. 大学生的第一课：手写最小SW Agent

**这是跳不过去的**。不写这个东西，大学可以说是白读或不及格。

最小Agent只需要：
- Terminal执行
- 文件读写（IO）
- Function calling / Tool calling
- Loop和流程控制

### 3. Cloud Code使用方法论（价值10万刀）

**三步走**：
1. 配置好所有权限和认证
2. 让Cloud Code自己解决整个问题
3. 充好钱，等着

对于99%的普通人来说，这是**最通用、最强大、最省时间**的方法。

### 4. AI Agent不是神：能力有边界

**不能做的事情**：
- 预测彩票、股价（违反因果论）
- 解决世界级数学难题（超出reasoning能力）
- 预测宏观经济走势（信息论限制）

**能做的事情**：
- 初中级编程任务
- 封闭环境内的自动化操作
- 有明确验证标准的任务

### 5. AI Agent的完美场景：四大条件

1. **封闭环境**：不依赖外部开放数据
2. **完整编译/仿真**：可以本地验证
3. **无限试错**：操作空间巨大
4. **精确验证**：结果可量化评估

推荐场景：
- 编程（本地算法、数据库、编译器）
- 电子设计自动化（EDA）
- MATLAB自动化
- 工业系统设计

### 6. Multi Agent：未来方向

核心观点：
- TOKEN会越来越便宜
- Multi Agent并发度会越来越高
- **Multi Agent是Post Training时代唯一可信的Scaling方式**

**不是过家家**：不能用"产品经理→架构师→程序员→QA"这种串联方式，而是要真正并行协作。
